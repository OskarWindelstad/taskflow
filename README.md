# TaskFlow

TaskFlow er en fullstack-applikasjon for oppgave- og prosjektstyring. Målet er å gjøre det enkelt å organisere oppgaver, prioritere arbeid og følge fremdrift.

## Funksjoner

- Opprette, redigere og slette oppgaver
- Organisere oppgaver i prosjekter
- Sette prioritet og frister
- Følge status og fremdrift
- Søke, filtrere og sortere oppgaver

## Teknologier

- **Frontend:** React, JavaScript, Vite og CSS
- **Backend:** Java 21, Spring Boot og Spring Data JPA
- **Database:** PostgreSQL
- **Verktøy:** Git, GitHub og Maven

## Starte prosjektet

**Backend** – fra prosjektmappen:

```bash
export DB_PASSWORD='ditt_passord'
./mvnw spring-boot:run
```

**Frontend** – i en ny terminal:

```bash
cd frontend
npm install
npm run dev
```

Åpne deretter adressen Vite viser i terminalen, vanligvis `http://localhost:5173`.
